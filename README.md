# Lab 3 - Word Count

This project implements the Chapter 10 Word Count assignment using OOP,
`pathlib`, `string`, file I/O, exception handling, dictionaries, and a
menu-driven interface.

## Required repository files

- `Lab10_arashid7868-1.py`
- `princess_mars.txt`
- `Tarzan.txt`
- `treasure_island.txt`
- `monte_cristo.txt`
- `requirements.txt`
- `README.md`

The four text files must be the exact files supplied by the instructor.

## Run

```text
python Lab10_arashid7868-1.py
```

The program uses only Python standard-library modules, but the course
requires `requirements.txt` to be generated with:

```text
pip freeze > requirements.txt
```

## Development approach

Use small, meaningful commits. Test after each logical feature before
committing and pushing.
